# Metal Cutting & Straightening – Web App

Single-page web app: record client, plate sizes, cutting size, gauge cutting, and pricing. Data is stored in your browser (IndexedDB).

## Where is the HTML file?

**Path:** `metal-cutting-app/index.html`  
(full path: `Dodia Brothers Application/metal-cutting-app/index.html`)

## How to open

- **On your computer:** Double-click `index.html` or open it from your browser (File → Open).
- **On your phone:** Host this folder on the web (e.g. Netlify, GitHub Pages) and open the URL in your phone’s browser.

## Features

- Client name, original plate size, cutting size (with auto weight and total cost)
- Gauge cutting section (optional)
- Recalculate button and automatic updates on mobile
- Save records to IndexedDB; list appears below the form
